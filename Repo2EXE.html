How to use it

      

        

          
1

          

            Create the folder
            
In your repo, create .github/workflows/ if it doesn't exist.

          

        

        

          
2

          

            Add the file
            
Save the YAML above as .github/workflows/build-exe.yml and commit it.

          

        

        

          
3

          

            Run the workflow
            
Go to Actions → Build EXE in your repo and click Run workflow.

          

        

        

          
4

          

            Download the .exe
            
When the run finishes, open it and download the Artifacts ZIP — your .exe is inside.

          

        

      

    


    

      💡
      GitHub Actions is free for public repos and included with 2,000 minutes/month on free private accounts. The built .exe runs on Windows only unless you add a matrix for Linux/macOS.
